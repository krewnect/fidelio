Empezar con Fidelio API

Usa nuestra API RESTful para emitir puntos, consultar saldos y construir experiencias de lealtad personalizadas en tu propia app o caja registradora.

Autenticación

Todas las peticiones a la API deben incluir tu clave secreta de servidor en los headers usando el formato Bearer Token.

Terminal 
curl -X GET https://api.fidelio.com/v2/users/me \
  -H "Authorization: Bearer sk_live_fidelio_123456789" \
  -H "Content-Type: application/json"

Seguridad de la API

Nunca expongas tu clave secreta (Secret Key) en código frontend (HTML/JS) ni en aplicaciones móviles. Todas las peticiones deben originarse desde tu servidor seguro (Backend).

Asignar Puntos (Ejemplo)

Para registrar una compra y asignarle puntos automáticamente a un cliente, usa el endpoint de transacciones.

POST /v2/transactions 
{
  "customer_email": "juan@example.com",
  "amount_spent": 150.50,
  "currency": "MXN",
  "receipt_id": "TICKET-88992"
